# Промпт для Claude Code: создание страницы партнёра KOZYR

Ты создаёшь страницу партнёра для сайта KOZYR (витрина рейкбек-сделок для покера).
Данные партнёра — в `_partner_drafts/{id}.json`. Эталон структуры — существующая
страница `ua/rooms/pokerbet/index.html` (рум) или `ua/clubs/klubok/index.html` (клуб).

## ЗАДАЧА

Создай страницу нового партнёра ПО ОБРАЗЦУ эталона, но с данными и текстом
под конкретного партнёра. Не копируй текст дословно — адаптируй под партнёра.

## ШАГ 1. Определи путь и эталон

```
type=room → эталон ua/rooms/pokerbet/index.html → путь /{country}/rooms/{id}/index.html
type=club → эталон ua/clubs/klubok/index.html   → путь /{country}/clubs/{id}/index.html
```

## ШАГ 2. Структура страницы (14 блоков)

Сохрани ВСЮ структуру эталона. Блоки (section id):
1. **hero** (хедер) — тег, H1, KOZYR Score, вердикт, факты, лого, CTA
2. **about** — О партнёре (2-4 абзаца, уникальный текст)
3. **legality** — Лицензия и статус
4. **software** — Софт и интерфейс
5. **games** — Игры и лимиты (таблица)
6. **traffic** — Трафик и поля
7. **deposits** — Депозиты и выплаты
8. **bonus** — Бонусы и промо
9. **rakeback** — Рейкбек
10. **kyc** — Верификация и KYC
11. **pros-cons** — Плюсы и минусы (из анкеты pros/cons)
12. **reviews** — Что говорят игроки
13. **cta** — Готов начать? (кнопка + ссылка)
14. **faq** — FAQ (из анкеты faq)

## ШАГ 3. Что БРАТЬ ИЗ АНКЕТЫ (не выдумывать)

Механические данные — строго из `_partner_drafts/{id}.json`:
- `name`, `score`, `license`, `currency`, `rakeLabel`, `payoutLabel`
- `games`, `limits`, `software`, `payments`, `bonus` → в таблицы/списки
- `pros`, `cons` → секция «Плюсы и минусы»
- `faq` → секция FAQ
- `logo_img` → логотип, `logo_from`/`logo_to` → градиент
- `country`, `acceptedCountries` → тег страны, плашка доступности
- `networkLabel` → название приложения (для клуба)
- `clubId`, `union` → для клуба (как вступить)

**НЕ ВЫДУМЫВАЙ ЦИФРЫ.** Если данных нет — пиши «уточняется у партнёра».

## ШАГ 4. Что ПИСАТЬ САМ (уникальный текст под SEO)

Текстовые секции — напиши осмысленно, естественно, с ключами:
- **about**: развёрнутое описание партнёра (кто, для кого, чем хорош)
- **legality**: объясни лицензию/юрисдикцию из `license`
- **software/traffic/deposits/bonus/rakeback/kyc**: living-текст по данным
- Тон — экспертный, честный, без «воды» и AI-шаблонности

## ШАГ 5. СТИЛЬ САЙТА (строго, эталон — ua/index.html)

### Логотип KOZYR — РЕАЛЬНЫЙ градиентный (НЕ примитивный!)
В `<header>` И `<footer>` вставь настоящий логотип:
```html
<svg viewBox="0 0 40 40" ...>
  <defs><linearGradient id="УНИКАЛЬНЫЙ_ID" x1="0" y1="0" x2="1" y2="1">
    <stop offset="0" stop-color="#14358F"/><stop offset="1" stop-color="#2A6BFF"/>
  </linearGradient></defs>
  <path d="M3770 6260..." fill="#2668FF" ... />
</svg>
```
НИКОГДА не используй примитивный `<path d="M12 8h9v20...">` — это ошибка.
Уникальные ID градиентов в header и footer (разные).

### Остальное
- **4 шрифта** в локальном `:root` (Space Grotesk, Inter, JetBrains Mono, Instrument Serif)
- **Плавающая кнопка Telegram** `.cx-fab` (не kozyr-enhance.js)
- **БЕЗ эмодзи** — только SVG-иконки, масти карт
- Тёмный hero, премиальная вёрстка как на эталоне

## ШАГ 6. ОБЯЗАТЕЛЬНЫЕ обновления

1. **partners.json** — добавь объект партнёра со всеми полями (НЕ partners.js!)
   Потом запустится `build_partners.py` → пересоберёт partners.js
2. **sitemap.xml** — добавь URL страницы (все языки) + hreflang RU↔UK
3. **UK-версия** — переведи на украинский → `/{country}/uk/{rooms|clubs}/{id}/`

## ШАГ 7. ПРАВИЛА КОНТЕНТА (критично)

- Упоминай ТОЛЬКО этого партнёра, НЕ конкурентов (GGPoker, PokerStars,
  PokerMatch, PPPoker, X-Poker — если это не сам партнёр)
- Без глубоких юридических/налоговых деталей (не давай юрконсультаций)
- Для клуба: объясни модель (агент, ID клуба, приложение), но без гарантий сумм
- Рейкбек: если у партнёра его нет — честно пиши «нет, только бонусы»

## ШАГ 8. ПРОВЕРКИ ПЕРЕД ЗАВЕРШЕНИЕМ

```bash
node --check partners.js          # синтаксис (после build_partners.py)
python automation/build_partners.py --check   # данные партнёра валидны
```
Визуально проверь:
- [ ] Логотип НАСТОЯЩИЙ (градиент), НЕ примитивный, в header И footer
- [ ] Все 14 секций на месте
- [ ] Таблицы лимитов/игр заполнены из анкеты
- [ ] Плюсы/минусы, FAQ — из анкеты
- [ ] Вёрстка не сломана, карточка ровная
- [ ] Нет эмодзи
- [ ] Внутренние ссылки рабочие
- [ ] UK-версия создана

## РЕЗУЛЬТАТ

Положи страницу в `_pending_partner/{id}/` (RU + UK).
НЕ в прод сразу — пользователь проверит превью в боте и решит публикацию.
