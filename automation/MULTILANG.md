# KOZYR — мульти-язычная генерация

## Идея коротко

Одна тема в Google Sheets = одна СТРАНА = все языки этой страны, генерируются
одним пайплайном и публикуются одновременно с корректными hreflang.

Для добавления новой страны — редактируется только один файл
`automation/country_config.py`.

---

## Как это устроено

### 1. Страна — центральная сущность

`automation/country_config.py`:
```python
COUNTRY_CONFIG = {
    "ua": {
        "name": "Украина",
        "flag": "🇺🇦",
        "languages": ["ru", "uk"],      # порядок ВАЖЕН: [0] = primary
        "primary_language": "ru",
        "url_prefix": "/ua",
    },
    # Раскомментируй когда захочешь запустить регион:
    # "pl": {..., "languages": ["pl", "uk"], "primary_language": "pl"},
    # "kz": {..., "languages": ["ru", "kk"], "primary_language": "ru"},
}
```

Одна тема в Sheets имеет две колонки:
- **`country`** — обязательно (`ua`, `pl`, `kz`)
- **`langs`** — необязательно, override. Если пусто → все языки страны.

Примеры:
| country | langs | Что произойдёт |
|---|---|---|
| `ua` | *(пусто)* | Сгенерит `ru` + переведёт на `uk` → опубликует обе |
| `ua` | `ru` | Только русская версия |
| `ua` | `uk` | Только украинская (перевод из ru или прямая генерация — TODO) |
| `pl` | *(пусто)* | (когда включим) сгенерит `pl` + переведёт на `uk` |

### 2. Генерация: primary + переводы

`automation/multilang_generator.py`:
```
1. Читает тему: country=ua, langs=["ru","uk"]
2. Определяет primary=ru
3. generate.py → _pending/{slug}/    (нативная генерация Claude)
4. translator.py → _pending_uk/{slug}/  (перевод той же статьи)
5. Копирует hero.webp во все переводы
6. Отправляет в TG ОДНО превью с обеими версиями
```

### 3. Перевод сохраняет структуру

`automation/translator.py` отправляет Claude весь JSON статьи (title,
sections, faq, russian_preview, tags) и просит перевести значения,
сохранив ключи и структуру. На выходе — тот же shape, но на украинском.

**Что переводится:**
- title, meta_title, meta_description, h1_title
- sections[i].heading, .paragraphs, .subheadings, .list_items
- faq[i].question, .answer
- russian_preview.title_ru, .summary_ru, .h2_translations[i].ru

**Что НЕ переводится:**
- URL (`/ua/`, `/ua/rooms/pokerbet/`)
- Названия брендов (PokerBet, KlubOk)
- Числа, даты, валюты
- Слуги статей

Промпт заточен под ru→uk: обращение на «ти», спец-термины покера
транслитом («рейкбек», «фолд»), «гривна → гривня».

### 4. Публикация: обе версии одновременно

`automation/multilang_publisher.py`:
```
1. Ищет _pending/{slug}/ и _pending_uk/{slug}/
2. Cross-link translation_of в обоих meta.json
3. publish.py рендерит /ua/blog/{slug}/index.html
4. publish.py рендерит /ua/uk/blog/{slug}/index.html
5. В обеих проставляет hreflang: ru-UA + uk-UA + x-default (=ru)
6. LANG_SWITCH_URL в шапке ведёт на конкретный перевод (не на дефолт)
7. Sitemap обновляется для обоих URL
```

### 5. Переключатель языков в шапке

`publish.py` теперь автоматически подставляет ссылку на реальный перевод:
- В `/ua/blog/foo/`  свитчер ведёт на `/ua/uk/blog/foo/`
- В `/ua/uk/blog/foo/`  свитчер ведёт на `/ua/blog/foo/`
- Если перевода нет — ведёт на дефолт (`/ua/uk/` или `/ua/`)

Логика в `publish.publish_article()`:
```python
if isinstance(translation_of, dict) and translation_of:
    other_lang, other_slug = next(iter(translation_of.items()))
    lang_switch_url = f"{other_cfg['url_prefix']}/{other_slug}/"
```

## Как выглядит превью в TG

Одно сообщение вместо двух. Пример:

```
📝 Новая статья на ревью 🇺🇦 Украина

📊 Quality: 87/100 — хорошо

─── 🇷🇺 RU ───
Как выбрать покерный рум с высоким рейкбеком в Украине
📊 2340 слов
Разбираем ключевые критерии выбора рума...
🔗 Полный текст

─── 🇺🇦 UK ───
Як обрати покерний рум з високим рейкбеком в Україні
📊 2280 слов
Розбираємо ключові критерії вибору руму...
🔗 Полный текст

[✅ Опубликовать все]  [🧾 Исходники]
[📄 🇷🇺 Текст]  [📄 🇺🇦 Текст]
[✏️ 🇷🇺 Правка] [✏️ 🇺🇦 Правка]
[🔄 Перегенерить] [❌ Отклонить]
```

Кнопки правки — раздельные по языкам. Открыв ✏️ 🇺🇦 Правка → правит
только украинскую версию. Русская не трогается.

## Добавление новой страны

**Пример: запуск Польши (языки польский + украинский).**

Шаг 1. Правишь `automation/country_config.py`:
```python
"pl": {
    "name": "Польша",
    "flag": "🇵🇱",
    "languages": ["pl", "uk"],
    "primary_language": "pl",
    "url_prefix": "/pl",
},
```

Шаг 2. Правишь `automation/lang_config.py` — добавляешь конфиги для `pl`
(если основной язык страны) и `pl_uk` (если украинский тоже есть).

Правда, тут есть нюанс: `uk` уже используется для украинской версии
Украины. Если мы будем использовать тот же `uk` для украинской версии
Польши, они разделят `_pending_uk/` каталог, что запутает. Решение —
использовать составные ключи для не-первичных языков: `ua_uk`, `pl_uk`.

Для Украины оставляем как есть (`ru` и `uk` для обратной совместимости),
для Польши сразу делаем `pl` и `pl_uk` с отдельными путями.

Шаг 3. Создаёшь `automation/prompts/system_prompt.pl.md`  для нативной
генерации на польском.

Шаг 4. Всё. `multilang_generator.py` подхватит `country=pl` из Sheets.

## Команды бота

- `/countries` — список настроенных стран
- `/suggested` — темы (показывает country/langs)
- `⚡ Генерить` под темой — запускает мультиязычный пайплайн
- `/translate slug uk` — перевести уже существующую статью (без ре-генерации)
- `✏️ 🇷🇺 Правка` / `✏️ 🇺🇦 Правка` — правка отдельной языковой версии

---

## Что делать со старыми статьями

**Пока не переводим автоматом.** У них нет `translation_of`, поэтому:
- Переключатель в их шапке ведёт на `/ua/uk/` (главную) — как заглушка
- В `sitemap.xml` они есть только на русском

Когда захочешь перевести старую статью:
```
/translate chto-takoe-reykbek-v-pokere uk
```
Бот прочитает `body.md` из `ua/blog/chto-takoe-reykbek-v-pokere/`,
переведёт и положит в `_pending_uk/`. Дальше — обычный publish flow.

## Технические детали

**Каталоги:**
- `_pending/`      — русские черновики (для обратной совместимости "ru" = "первичный украинский")
- `_pending_uk/`   — украинские черновики
- `_pending_pl/`   — польские (когда появятся)
- `ua/blog/`       — опубликованные русские
- `ua/uk/blog/`    — опубликованные украинские
- `pl/blog/`       — польские (когда появятся)

**Slug общий для всех переводов** — важно для hreflang и переключателя.
Один и тот же `foo-bar` существует в двух местах, отличаются только языком.

**article.json** сохраняется в `_pending/{slug}/` — это полная структурированная
статья, которую translator.py использует как исходник для перевода. Без неё
он падает в fallback-режим (переводит просто markdown body.md).

**Перевод стоит ~$0.03-0.05** за статью 2000 слов на Claude Sonnet 4.5.
Дешевле чем повторная генерация с нуля ($0.20-0.30).
